# a3-sphere-group-prj
This is the A3 group project for the S.O.S. after-effect at the RRM


# Royal Saskatchewan Museum — Sphere of Science

## 1. Project Overview
A paper-cutout animation introducing the North American bison for the Royal Saskatchewan Museum Sphere of Science.

## 2. Research
- Technique researched: Research on bison in Canada.
- How the technique is used: Create assets of bison images, background, foreground, follow the paper cut-out style, use text-to-speech to generate the narration, and create animation in After Effects using those assets. 
- Why it is appropriate for the Sphere: The animations are created and organized as pre-comp sets; the RRM can use those pre-comps to reproduce their desired video, modify, or add on to their Sphere software adaptively. 
- We created multiple assets using a scrap paper/ scrap book overlay texture on top of stock images  and vectors that are cropped like cut outs of paper. As for the animations, simple movements, frame per frame textbook-like animation was used.
  
## 3. Visual Direction
The bison video is for children's education; we decided to make it in a paper cut-out style, with a manipulated background and basic animations. It is a type of art style that has been used for years, so we figured that using this fun and creative art style fits RSM's overall look and brand. 

## 4. Production Workflow
1. Research and sketch ideas.
2. Create and separate illustration layers.
3. Import assets into After Effects.
4. Animate and preview compositions.
5. Export and test the final files.
6. Package the assets with their SOS files.

## 5. Asset Inventory
* Background
* Foreground
* Bison
* Sound
* Vector elements
* scrap paper texture overlay
* Maps
* indigenous people
* Ecosystem 

## 6. Technical Specifications
* Image assets are .png with transparent backgrounds
* After Effects comp with a 2:1 pixel ratio, 2048x1024, 30 FPS.
* Animation video output using the H. 264 codec (.mp4) at 30 Mbps.
